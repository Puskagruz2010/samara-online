# Samara Online

Мультиплеер для My Summer Car для своей компании: игра по сети через Steam, голос с затуханием по расстоянию, общий сейв хоста.

Форк [MSC Co-op](https://github.com/kubilaiswf/mscoop) (автор kubilay), лицензия CC BY-NC-SA 4.0 (см. `LICENSE`). Оригинальное описание лежит в [README.upstream.md](README.upstream.md).

## Скачать

Последняя версия: **[Releases → SamaraOnline.zip](../../releases/latest)**. Инструкция по установке лежит внутри архива, в файле `КАК УСТАНОВИТЬ.txt`.

Если коротко:
1. Поставить [MSCLoader](https://github.com/piotrulos/MSCModLoader/releases) (1.4.2 или новее).
2. Скопировать папку `Mods` из архива в папку игры с заменой файлов.
3. Запускать игру через Steam. Хост создаёт лобби в главном меню (панель MSC Co-op справа), остальные заходят по приглашению.

У всех игроков должна быть одна и та же версия мода.

## Отличия от MSC Co-op

- Голосовой чат: CapsLock — говорить рядом, боковая кнопка мыши — рация на всех; голос пьяного плывёт.
- Мод `MSCCoop.Recon`: телепорт к другу, пригон машины, деньги, трассировка FSM для отладки (консоль, клавиша Ё; список команд — `test` и `recon`).
- Видимая струя мочи у других игроков.
- Свой протокол (110): с обычным MSC Co-op не смешивается.
